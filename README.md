# car-ads-dashboard
Proyecto del Sprint 7

## Descripción del Proyecto
Desarrollar una aplicación web que muestre un conjunto de datos de anuncios de venta de vehículos, en la cual un potencial comprador pueda aplicar tres filtros encadenados (año, marca/modelo, y precio), así como visualizar gráficos como Dispersión de precios vs Año e Histograma de precios.
